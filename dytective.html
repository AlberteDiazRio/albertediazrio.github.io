DESCRIPTION

Dytective is an app that uses interactive games to help detect and support dyslexia.

It analyzes users’ performance through AI-driven cognitive exercises to assess reading-related skills and provide personalized training.

It combines scientific research and gamified design to create engaging, accessible tools for early detection and intervention.

My role in the project was Fullstack Videogame Programmer and Designer. I developed a newer version of Dytective app that will be published soon

I programmed main game mechanics and designed interactive educational experiences and minigames, optimizing gameplay and UX. I also implemented automatic testing and some tools that make the development way faster and eficient
